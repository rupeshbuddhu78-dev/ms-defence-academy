# Build Toolchain References

- Flutter's official manual installation guide describes downloading and extracting the latest stable SDK bundle: https://docs.flutter.dev/install/manual
- Flutter's Android setup guide covers Android SDK/toolchain requirements: https://docs.flutter.dev/platform-integration/android/setup
- Android's official SDK tools guide documents SDK packages and `sdkmanager`: https://developer.android.com/tools
- Android Studio's official download page provides the standalone command-line tools package: https://developer.android.com/studio

The build setup used the current stable Linux x64 Flutter SDK, Android SDK command-line tools, Android platform/build tools, and a full JDK. These references are informational and are not bundled SDK binaries.
